# vpn-bypass-mcp

MCP server for [VPN Bypass](https://github.com/GeiserX/VPN-Bypass), the macOS menu bar app that routes the domains and services you pick around your VPN. It lets an AI agent read the app's state and change its routing through the app's local control socket.

The server is being built. The first release will follow.
